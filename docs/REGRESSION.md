## 执行基线

- 安装本插件后重启 `dsh web` 并刷新浏览器（改动 client.js 后必须重启，composition 缓存会掩盖问题；若页面经 HMR 多次热更，先整页刷新再测）。
- 除注明外，全部条目在「Fold」显示模式下执行。
- 会话样本须包含：多段正文、多工具调用、思维链、被中止/中断的轮、Ctrl+Enter 插入的消息。
- 浏览器条目判定以实际操作 + DOM 断言/截图为准。
- 全局失败条件：`document.querySelectorAll('[data-slot-error]').length !== 0`，或页面存在 `data-dsh-debug-error` / `window.__DF_*` 调试探针。

- 预期：`height` 约 33px；`border-bottom` 为细线；背景透明；收起时 chevron `rotate(-90deg)`、展开时 `rotate(0)`；非卡片/圆角背景样式。（⬜ 待执行；实测采样已见 33px）

### T-B2 文案格式（M + B ✅）
- 分别检查含工具调用、仅思考、无正文尾段三类栏。
- 预期：文案分别为 `N 个工具调用 · M 条消息`、`M 条消息` 或 `思考了一会儿`、`N 个工具调用` 或 `思考了一会儿`；展开/收起只旋转 chevron，不改变文字。

### T-B3 栏锚定段首：展开步骤在栏下方、收起紧贴其后正文（B2/B15/B16）（M + B ✅）
- 构造多正文轮（正文 → 过程 → 正文）：分别检查收起与展开两种状态；另查 steering 封口段、流式尾段、轮首段。
- 预期：收起时每条栏紧贴其各自正文上方，不集中堆在轮顶 turn-process 座位；展开某栏后该段步骤出现在栏**下方**（`[栏][步骤][正文]`，官方 turn-process 语义），不得出现在栏上方——唯一例外：steering 后段首步是官方渲染（tool-call/context）时，闭合段的栏落座封口正文上方（收起仍紧贴其后正文）。
- 实测注记（2026-09-07）：多正文轮展开第二栏，tool-call 位于栏下方（栏 bottom 172 / tool-call top 188，视口坐标），收起后紧贴其后正文；轮首段栏落座 turn-process 座位；0 debug error。

## C 折叠内容正确性

### T-C1 正文永不折叠（M + B ✅）
- 在任意折叠状态下检查多正文会话。
- 预期：assistant-step 的正文 block 始终可见；收起全部栏后正文完整、内容不变。

### T-C2 计数与实际一致（M + B ✅）
- 逐个展开折叠栏并清点可见步骤。
- 预期：可见 tool-call 数等于栏文案「N 个工具调用」；思维链与工具调用均不丢失，不得出现“只剩思维链、工具调用消失”。

### T-C3 中止/中断轮：收起隐藏、展开可见（B10）（M + B ✅）
- 打开含被中止/中断轮（无最终正文，仅 reasoning + tool-call）的会话：先在收起状态检查对话流，再点击该轮折叠栏展开。
- 预期：
  - 收起时该轮 0 条 tool-call、思维链溢出到对话流（无预览——轮已闭合）；
  - 展开后该段全部步骤（reasoning + tool-call）可见；
  - 再收起，恢复 0 可见。
- 历史：第一轮修复曾反向过隐藏（展开无内容），随架构重构修复。

### T-C4 加载历史后过程不溢出（B11）（M + B ✅）
- 点一次「加载更早」载出更多历史后检查。
- 预期：折叠态下 `[data-chat-flow-kind="tool-call"]` 可见数为 0；动态样式规则覆盖当前全部 tool-call，不存在“无规则却可见”的节点。

### T-C5 代码块正文正常渲染（B9）（B ✅）

## G 插入与轮边界

### T-G1 Ctrl+Enter 插入开启新折叠栏（B14）（M + B ✅）
- 在一轮已有折叠栏的对话进行中或结束后，按 Ctrl+Enter 插入一条消息，等待新步骤产生。
- 预期：Ctrl+Enter 在代码逻辑上是新一轮对话（steering 边界），插入点之后产生的过程步骤必须归入一个**新的折叠栏**（收起时随之隐藏、展开可见），不得并入插入点之前的任何栏。
- 实测注记：插入点落在运行中的轮时，宿主可能将消息排队为新轮（turn 号递增）——新轮天然独立成栏，同样满足轨迹不变量 I1；同 turn 内的 steering 切段由机械化用例覆盖。

### T-G2 steering 边界切段（M ✅）
- 检查同一 turn 内含 steering 插入的多段过程。
- 预期：steering 前后的过程分属不同段、不同折叠栏，计数互不包含。
